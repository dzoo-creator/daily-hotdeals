# 오늘의 핫딜

생필품·먹거리·육아용품의 평소 가격보다 저렴한 딜과 여행·숙박 특가를 보여주는 정적 웹앱입니다. 아이폰 사파리에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

**음식**은 `🥩신선식품(과일·생선·고기)` · `🧊냉동류` · `🍲밀키트·간편식` · `🥫통조림·가공` · `🥤음료·유제품·간식` 5개 세부 분류로 나눠 볼 수 있습니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 전체 (CSS·JS 포함, 빌드 과정 없음) |
| `deals.json` | 딜 데이터. **이 파일만 갱신하면 화면이 자동 반영됩니다.** |
| `.nojekyll` | GitHub Pages에서 Jekyll 처리를 건너뛰게 함 |

## 피클 데이터 갱신 절차

1. 아침·점심마다 판매처 상품 페이지를 열어 구매 가능한 상품 가격, 옵션·수량, 쿠폰·카드·멤버십 조건, 배송료와 재고를 확인합니다. 국내 생필품·먹거리·육아용품 중심으로 업데이트하고, 일반 가전·전자제품과 의류는 새 수집에서 제외합니다.
2. 같은 구성의 가격 이력에서 기간과 평균가를 확인한 뒤 `priceHistory`에 넣습니다. 평균가보다 낮아졌으면 추천에 표시됩니다. 여행·숙박은 동일 객실/상품, 날짜·인원·취소 조건에서 비교가 가능한 경우에만 평균가를 기록합니다.
3. 쿠팡 이외 판매처도 찾아 `priceOffers`에 추가합니다. 재확인이 안 된 판매가격과 종료·품절 상품은 빼고, 상품 1개를 국내 일반 주소로 주문할 때 적용되는 배송비를 `shippingCost`로 입력합니다.
4. 매번 `date`(한국 날짜), `updatedAt`(한국 시간 오프셋을 포함한 ISO 8601 시각), `deals`를 함께 갱신합니다. `deals.json`의 JSON 유효성과 중복 ID를 확인하고 `main`에 반영하면 GitHub Pages에서 새 데이터를 배포합니다. 오전과 점심이 같은 날짜여도 `updatedAt`은 새 시각이어야 합니다.
5. 페이지를 열거나 새로고침하면 `deals.json`을 불러옵니다. 페이지가 보이는 동안 5분마다 갱신을 확인하고, 다시 돌아온 탭도 마지막 확인 후 5분이 지났으면 데이터를 확인합니다. 오프라인에는 브라우저에 마지막으로 저장한 데이터나 HTML 내장 사본을 보여줍니다. 딜을 크게 바꿨다면 HTML의 `fallback-deals` 사본도 맞춰 주세요.

## deals.json 필드

```json
{
  "schemaVersion": 4,
  "date": "2026-11-25",
  "updatedAt": "2026-11-25T08:50:00+09:00",
  "malls": ["쿠팡", "무신사"],
  "deals": [
    {
      "id": "food-coke-190-30",
      "category": "food",
      "subCategory": "fresh",
      "mall": "쿠팡",
      "tag": "골드박스",
      "title": "코카콜라 오리지널 190ml 30개",
      "price": 13280,
      "priceText": "13,280원",
      "unit": "캔당 443원",
      "was": "평소 16,200원대",
      "refs": ["역대 최저 13,180원"],
      "saving": "역대 최저가에 100원 차이",
      "shipping": "무료배송",
      "note": "190ml × 30캔",
      "how_to": "쿠팡 골드박스 특가 · 별도 쿠폰 없이 바로 이 가격",
      "coupon_links": [
        { "label": "집요한 쿠폰 받기", "url": "https://ozip.me/..." }
      ],
      "url": "https://www.coupang.com/...",
      "linkLabel": "쿠팡에서 구매",
      "linkType": "product",
      "priceCondition": "와우회원가",
      "shippingCost": 0,
      "priceHistory": null,
      "priceOffers": []
    }
  ]
}
```

- `category`: `baby` | `living` | `food` | `fashion` | `travel`
- `subCategory`: 음식 전용 — `fresh`(신선식품) | `frozen`(냉동류) | `mealkit`(밀키트·간편식) | `canned`(통조림·가공) | `drink`(음료·유제품·간식). 다른 카테고리는 생략
- `price`: 숫자. 행사처럼 가격이 없으면 `null` + `priceText`에 문구
- `was`: 취소선으로 보여줄 평소가 (없으면 `null`)
- `refs`: 비교 기준 문구 배열 (기존 최저가·타몰 최저가 등)
- `saving`: 할인 근거 한 줄 (없으면 `null`)
- `shipping`: `무료배송`, `로켓배송` 등 (없으면 `null`)
- `how_to`: 할인 받는 방법 한 줄 (선착순 쿠폰·페이/카드 조건 등)
- `coupon_links`: `[{ "label", "url" }]` 쿠폰·혜택 페이지 링크 (없으면 `[]`)
- `linkType`: `product`(상품 페이지) | `search`(몰 검색 링크) | `app`
- `malls`: 쇼핑몰 필터 목록 순서. 비교 판매처도 자동으로 추가됩니다.
- `priceCondition`: 대표 판매가에 필요한 쿠폰·카드·멤버십 조건을 짧게 표기합니다. 없으면 생략합니다.
- `shippingCost`: 판매 단위 1개를 주문할 때 적용되는 배송비(원). 무료배송은 `0`, 배송료가 조건부거나 미확인이면 `null` 또는 생략. 여행은 세금·필수 수수료 추가액을 쓰며, 이미 예약가에 포함됐음을 확인했으면 `0`입니다.
- `priceHistory`: 동일 상품·옵션의 실제 판매 가격 기록에서 확인한 평균. `{ "averagePrice": 6090, "period": "3주", "source": "로우차트" }` 형식입니다. 출처 링크는 `sourceUrl`, 출처에서 근삿값으로 표시한 경우 `approximate: true`를 추가합니다. 정가·다른 상품·이전 하루 가격·기록 최저가만 있는 경우에는 `null` 또는 생략합니다.
- `priceOffers`: 동일 상품을 다른 쇼핑몰에서 찾은 경우에만 아래 형식으로 추가합니다. 생략하거나 빈 배열을 넣을 수 있습니다.

### 비교 판매처 등록

```json
{
  "mall": "11번가",
  "price": 17800,
  "url": "https://www.11st.co.kr/products/8912362617",
  "shippingCost": 3000,
  "checkedOn": "2026-11-27"
}
```

- `mall`, `price`(배송비 제외 상품가), `url`(실제 상품 페이지나 해당 상품의 가격 비교표)은 필수입니다.
- `shippingCost`, `condition`(쿠폰·회원·카드 등), `checkedOn`(YYYY-MM-DD), `sourceUrl`(가격을 확인한 별도 출처)은 선택입니다. 비교 판매처의 가격 이력이 있으면 그 항목 안에 별도로 `priceHistory`를 기록합니다. `url`이 비교표면 `linkType: "comparison"`으로 표시합니다.
- 브랜드·옵션·용량과 묶음 수량이 모두 같은 판매가만 넣습니다. 품절·만료가 확인된 판매가와 과거 최저가는 순위에서 제외합니다.
- 배송비가 확인된 가격은 상품가에 배송비를 더해 최대 3위까지 표시합니다. 배송비를 확인하지 못한 판매처는 상품가와 함께 표시합니다. 쇼핑몰 필터와 쿠팡 제외 설정이 순위와 평균 대비 계산에 반영됩니다.

## 화면 기능

- 기본 화면은 생필품·먹거리·육아·여행 중 근거 있는 평균가보다 낮은 상품을 절감률순으로 보여줍니다. 카테고리와 전체 목록에서도 가격과 구매 링크를 확인할 수 있습니다.
- 음식 탭을 열면 세부 분류 칩(전체·신선식품·냉동류·밀키트·간편식·통조림·가공·음료·유제품·간식)이 나타나고, 카드에도 세부 분류 배지가 붙습니다.
- 쇼핑몰 필터, 상품명·브랜드·판매처 검색, 기기에 저장되는 쿠팡 제외 설정
- 상품별 판매처 가격 순위와 판매 페이지 또는 비교표 링크
- 찜하기(하트)는 브라우저 localStorage에 저장
- `deals.json`을 못 불러오면 내장 데이터로 표시(오프라인 대응)
