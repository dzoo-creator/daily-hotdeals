# 오늘의 핫딜

매일 아침 육아·생활·음식·의류·여행 핫딜을 모아 보여주는 정적 웹앱입니다. 아이폰 사파리에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

**음식**은 `🥩신선식품(과일·생선·고기)` · `🧊냉동류` · `🍲밀키트·간편식` · `🥫통조림·가공` · `🥤음료·유제품·간식` 5개 세부 분류로 나눠 볼 수 있습니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 전체 (CSS·JS 포함, 빌드 과정 없음) |
| `deals.json` | 딜 데이터. **이 파일만 갱신하면 화면이 자동 반영됩니다.** |
| `.nojekyll` | GitHub Pages에서 Jekyll 처리를 건너뛰게 함 |

## 딜 갱신 방법

1. `deals.json`의 `date`, `updatedAt`, `deals` 배열을 고칩니다.
2. `main` 브랜치에 커밋·푸시하면 GitHub Pages에 반영됩니다(보통 1분 이내).
3. `index.html` 안의 `<script id="fallback-deals">` 는 오프라인·파일 직접 열기용 사본입니다. 딜을 크게 바꿨다면 이 사본도 같은 내용으로 맞춰 주세요.

## deals.json 필드

```json
{
  "schemaVersion": 3,
  "date": "2026-11-25",
  "updatedAt": "2026-11-25T08:50:00+09:00",
  "malls": ["쿠팡", "무신사"],
  "deals": [
    {
      "id": "food-coke-190-30",
      "category": "food",
      "subCategory": "fresh",
      "mall": "쿠팡",
      "tag": "골드박스",
      "title": "코카콜라 오리지널 190ml 30개",
      "price": 13280,
      "priceText": "13,280원",
      "unit": "캔당 443원",
      "was": "평소 16,200원대",
      "refs": ["역대 최저 13,180원"],
      "saving": "역대 최저가에 100원 차이",
      "shipping": "무료배송",
      "note": "190ml × 30캔",
      "how_to": "쿠팡 골드박스 특가 · 별도 쿠폰 없이 바로 이 가격",
      "coupon_links": [
        { "label": "집요한 쿠폰 받기", "url": "https://ozip.me/..." }
      ],
      "url": "https://www.coupang.com/...",
      "linkLabel": "쿠팡에서 구매",
      "linkType": "product",
      "priceCondition": "와우회원가",
      "priceOffers": []
    }
  ]
}
```

- `category`: `baby` | `living` | `food` | `fashion` | `travel`
- `subCategory`: 음식 전용 — `fresh`(신선식품) | `frozen`(냉동류) | `mealkit`(밀키트·간편식) | `canned`(통조림·가공) | `drink`(음료·유제품·간식). 다른 카테고리는 생략
- `price`: 숫자. 행사처럼 가격이 없으면 `null` + `priceText`에 문구
- `was`: 취소선으로 보여줄 평소가 (없으면 `null`)
- `refs`: 비교 기준 문구 배열 (기존 최저가·타몰 최저가 등)
- `saving`: 할인 근거 한 줄 (없으면 `null`)
- `shipping`: `무료배송`, `로켓배송` 등 (없으면 `null`)
- `how_to`: 할인 받는 방법 한 줄 (선착순 쿠폰·페이/카드 조건 등)
- `coupon_links`: `[{ "label", "url" }]` 쿠폰·혜택 페이지 링크 (없으면 `[]`)
- `linkType`: `product`(상품 페이지) | `search`(몰 검색 링크) | `app`
- `malls`: 쇼핑몰 필터 목록 순서. 비교 판매처도 자동으로 추가됩니다.
- `priceCondition`: 대표 판매가에 필요한 쿠폰·카드·멤버십 조건을 짧게 표기합니다. 없으면 생략합니다.
- `priceOffers`: 동일 상품을 다른 쇼핑몰에서 찾은 경우에만 아래 형식으로 추가합니다. 생략하거나 빈 배열을 넣을 수 있습니다.

### 비교 판매처 등록

```json
{
  "mall": "11번가",
  "price": 17800,
  "url": "https://www.11st.co.kr/products/8912362617",
  "shipping": "배송비 3,000원",
  "checkedOn": "2026-11-27"
}
```

- `mall`, `price`(배송비 제외 상품가), `url`(실제 상품 페이지나 해당 상품의 가격 비교표)은 필수입니다.
- `shipping`, `condition`(쿠폰·회원·카드 등), `checkedOn`(YYYY-MM-DD), `sourceUrl`(가격을 확인한 별도 출처)은 선택입니다. `url`이 비교표면 `linkType: "comparison"`으로 표시합니다.
- 브랜드·옵션·용량과 묶음 수량이 모두 같은 판매가만 넣습니다. 품절·만료가 확인된 판매가와 과거 최저가는 순위에서 제외합니다.
- 대표 판매가와 비교 판매가를 합쳐 쇼핑몰당 가장 낮은 등록 상품가를 최대 3위까지 보여줍니다. 두 곳 이상에 숫자 가격이 있을 때 순위를 표시합니다. 쇼핑몰 필터와 쿠팡 제외 설정을 적용한 판매처만 비교합니다.

## 화면 기능

- 카테고리 탭: 전체 / 육아 / 생활 / 음식 / 의류 / 여행·호텔 / 찜한 딜
- 음식 탭을 열면 세부 분류 칩(전체·신선식품·냉동류·밀키트·간편식·통조림·가공·음료·유제품·간식)이 나타나고, 카드에도 세부 분류 배지가 붙습니다.
- 쇼핑몰 필터, 상품명·브랜드·판매처 검색, 기기에 저장되는 쿠팡 제외 설정
- 상품별 판매처 가격 순위와 판매 페이지 또는 비교표 링크
- 찜하기(하트)는 브라우저 localStorage에 저장
- `deals.json`을 못 불러오면 내장 데이터로 표시(오프라인 대응)
